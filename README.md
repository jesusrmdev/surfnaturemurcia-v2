## Project Overview

Complete redesign and redevelopment of the Surf Nature Murcia website.

This project is being rebuilt from scratch to replace the current WordPress + Elementor website with a modern, fast, maintainable and SEO-optimized solution built using HTML, CSS and Vanilla JavaScript.

## Business Goal

Increase visibility, trust and conversions for Surf Nature Murcia through a modern, high-performance website focused on user experience, local SEO and long-term scalability.

## Objectives

- Improve performance and loading speed.
- Improve SEO and accessibility.
- Create a scalable codebase.
- Deliver a professional user experience.
- Showcase the project as a professional portfolio piece.
- Document the complete development process.

## Project Scope

The project includes:

- Website audit and benchmarking.
- Information architecture redesign.
- UX/UI redesign.
- Responsive frontend development.
- SEO optimization.
- Performance optimization.
- Accessibility improvements.
- Deployment and launch.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Git
- GitHub
- Visual Studio Code

## Development Approach

The project follows a structured product development workflow:

Audit of the current website and identification of UX/UI issues.  
Definition of business goals, conversion strategy and user flow.  
UX/UI redesign with focus on clarity, hierarchy and conversion.  
Creation of a scalable design system (colors, typography, spacing, components).  
Implementation of frontend structure using HTML + modular CSS architecture.  
Initial homepage development (hero, sections, pricing cards).  
Iterative visual refinement and UI polishing.  
SEO optimization (structure, headings, semantic HTML, metadata).  
Testing, accessibility validation and responsive optimization.  
Deployment preparation and continuous improvement cycle.
